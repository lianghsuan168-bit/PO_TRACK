預設會嘗試讀取 ./data/po.xlsx。也可以手動上傳 PO 檔後直接點選登打。
部署步驟：
1. 建立 Google Sheet，第一列可留空，Apps Script 會自動建立標題。
2. 到「擴充功能 → Apps Script」，貼上我附的 google_apps_script_invoice.gs。
3. 修改 Apps Script 裡的 SPREADSHEET_ID。
4. 部署成 Web App，執行身分選「我」，存取權選「知道連結的任何人」。
5. 把 Web App URL 貼到本頁與主頁的 GOOGLE_APPS_SCRIPT_URL。

若公司環境不允許「任何人」存取，可改成公司網域內使用者，但使用者需要登入 Google 帳號。
